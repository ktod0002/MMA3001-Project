Apple Tree 3D Reconstruction

Overview

The aim of this project was to develop a method of generating a simplified 3D model of an apple tree using RGB images and depth data. The model focuses on the main trunk and branches, with the goal of providing useful information for path planning in an apple-picking robot.

Method

A convolutional neural network was trained using TensorFlow to identify the tree structure from an RGB image. The images were cropped and resized to 256 × 256 pixels, with data augmentation used to help reduce overfitting. The predicted 2D mask was then combined with depth data to estimate the positions of the branches in 3D space. Interpolation and curve fitting were used where depth measurements were incomplete. Finally, the 3D model was generated by connecting points along the branches using cylinders.

Improvements

The original method used overlapping spheres to generate the model. This was later replaced with cylinders, which significantly reduced the number of faces while producing nearly identical results.

Processing time: Reduced from 1.1269 s to 0.6735 s, a 40% reduction overall.

Peak memory usage: Reduced from 143.86 MB to 47.06 MB, a 73% reduction.

Reconstruction time: Approximately 55% faster when excluding the neural network prediction time.

Libraries Used:
Python, TensorFlow, NumPy and Trimesh.
